# Configuration Register

Behaviour-changing configuration is typed, validated, scoped and documented. Secrets live only in the server environment or an approved secret manager; this register holds metadata, never values.

| Config ID | Key | Scope | Type | Default | Required | Secret | Security / residency impact | Source of truth | Status |
|---|---|---|---|---|---|---|---|---|---|
| CFG-APP-001 | `APP_NAME` | Application | string | SemantIQ | Yes | No | Shown in the top bar and the browser title | Server `.env` | Implemented |
| CFG-BRAND-001 | `brand.assets_path` | Application | string | `/brand` | Yes | No | Where the approved logo and favicon pack is served from | `config/brand.php` | Implemented |
| CFG-AUTH-001 | `services.microsoft.tenant` / `client_id` / `redirect` | Application | string | none | For SSO | No | Must match the Entra app registration exactly | Server `.env` | Implemented, unset on the server |
| CFG-AUTH-002 | `services.microsoft.client_secret` | Application | string | none | For SSO | **Yes** | Compromise permits impersonation of the application. Never committed, never sent to the browser, never logged | Server `.env` | Implemented, unset on the server |
| CFG-NAV-001 | `navigation.policies` | Application | map | see file | Yes | No | Defines the minimum tier, Auditor acceptance and domain requirement for every gated node and route | `config/navigation.php` | Implemented |
| CFG-NAV-002 | `navigation.clusters` | Application | tree | see file | Yes | No | The rail, generated from `doc/MENU_STRUCTURE.md` and mapped onto the four fixed clusters | `config/navigation.php` | Implemented |
| CFG-SOV-001 | Approved storage and processing geographies | Organisation | list | unset | Before production | No | Unset blocks production activation | Not yet built | Planned, Phase 02 |
| CFG-PLAT-001 | `platform.settings` | Application | catalogue | see file | Yes | No | The contract for every runtime setting: key, category, type, default, validation, editable tier, audit and sensitivity. A key not declared here cannot be read or written | `config/platform.php` | Implemented |
| CFG-PLAT-002 | `platform.flags` | Application | catalogue | see file | Yes | No | The contract for every capability flag, including the precondition that makes a switch safe in one direction only. An undeclared flag reads OFF | `config/platform.php` | Implemented |
| CFG-PLAT-003 | `platform.bootstrap_organisation_code` | Application | string | `PRIMARY` | Yes | No | Names the organisation row the bootstrap migration creates. ADM-002 edits that row, never creates a second | `config/platform.php` | Implemented |
| CFG-SET-001 | `app.display_name`, `app.support_contact`, `app.default_locale`, `app.default_time_zone`, `app.pagination_default`, `notifications.default_channel` | Organisation | typed | see catalogue | No | No | Presentation and list defaults. `support_contact` is shown to signed-in people, so it must be a monitored team address | `system_settings` overriding `config/platform.php` | Implemented |
| CFG-SET-002 | `environment.label`, `environment.maintenance_mode`, `environment.maintenance_message` | Organisation | typed | empty / false / empty | No | No | The maintenance message is shown to every signed-in person and must carry no incident detail, host name or customer information | `system_settings` overriding `config/platform.php` | Implemented |
| CFG-FLAG-001 | `identity.local_sign_in` | Organisation | boolean | true | No | No | Offers the email and password form. Turning it OFF requires Microsoft sign-in to be configured, or the instance would have no way in | `feature_flags` overriding `config/platform.php` | Implemented |
| CFG-FLAG-002 | `platform.extended_diagnostics` | Organisation | boolean | false | No | No | Adds driver names and runtime detail to Diagnostics. No credential and no customer data, but it describes the host, so it is off by default | `feature_flags` overriding `config/platform.php` | Implemented |
| CFG-NAV-003 | `navigation.policies.*.permission` | Application | string | none | No | No | Lets a rail node name a declared permission as well as a tier. Both must hold. An undeclared permission denies, so a typo removes a branch of the rail rather than opening one | `config/navigation.php` | Implemented |
| CFG-PERM-001 | `PermissionRegistry` catalogue | Application | code | see file | Yes | No | The contract for every permission: key, module, ceiling, auto-grant tier, risk and audit requirement. **Not configuration data** - it is code, because a permission nothing checks must not be creatable | `app/Modules/Identity/Support/PermissionRegistry.php` | Implemented |
