# Configuration Register

All behavior-changing configuration must be typed, validated, scoped and documented. Secrets are stored only in the approved secret manager; this register stores metadata, never secret values.

Organisation-scoped `DataProtection:*` settings are columns on `data_protection_profiles`, one row per version. The "Source of truth" column names the column so the register and the schema cannot drift apart.
