# Data Context Register

Every production dataset/entity must have a named business/data owner and a defined classification, residency and retention policy before go-live.

Storage and processing geography read "Per DataProtectionProfile (unset)" wherever the value is the customer's to state. Decision D5 in `doc/execution/PHASE-00-PLAN.md` defers those values to Phase 02, where something is first provisioned; `VAL-SOV-GEO-001` blocks production activation while they are unset. The control plane itself runs on cPanel MySQL, whose hosting geography must be confirmed and recorded before go-live rather than assumed.
