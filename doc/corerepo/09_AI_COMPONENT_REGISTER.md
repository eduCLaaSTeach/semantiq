# AI Component Register

Every runtime AI component or agent, kept as the AI inventory per AI Inventory in `.claude/rules/ai-agent-governance.md`. Model / Catalog Ref names the AI model catalog record it calls, per `.claude/rules/ai-model-catalog.md`; never a key or a credential. Prompt Version names each released prompt version it uses. Kill Switch names the feature's switch, per `.claude/rules/ai-guardrails.md`. Risk Level uses the project's confirmed scale, never an invented one.
